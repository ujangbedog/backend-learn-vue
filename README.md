# backend-vue

This project is a backend built using Express and TypeScript.

## Version

1.0.0

## Installation

To install dependencies, run:

```bash
bun install
```

## Running the Project

To run the project in development mode, use:

```bash
bun run index.ts
```

or

```bash
bun run dev
```

## To build the project, run:

### Build

```bash
bun run build
```

### Run after Build

```bash
bun run start
```
